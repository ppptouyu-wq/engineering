01 / 简历诊断

简历优化

针对目标岗位检查简历，找出可以补充证据或改进表达的地方。

支持文字型 PDF（5 MB 内、最多 10 页）及 UTF-8 文本。提取后请核对排版与正文，扫描件需先进行 OCR。

开启后，简历正文与岗位描述会发送至 DeepSeek。请先移除联系方式等个人信息，并核对生成稿。
02 / 岗位练习

模拟面试

选择岗位，逐题用文字作答，提交后查看评分和逐题点评。

启用 DeepSeek 后用于定制出题。使用本地题库时，按所选岗位与难度出题。
练习题数

当前使用本地题库和规则评分。配置 DeepSeek API Key 后可启用 DeepSeek。

每题需填写 10–2,500 字符。

05 / 简历迭代

简历版本

保存不同岗位的简历稿，对照修改内容与诊断维度。

比较两个版本

两份简历均采用修改后版本的目标岗位和岗位描述计算规则分。
