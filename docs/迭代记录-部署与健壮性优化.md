# 部署与健壮性优化

日期：2026-11-16。

## 优化目标

本轮保持简历诊断、模拟面试、历史记录和 DeepSeek 回退流程不变，重点改善部署可用性、异常数据兼容和运行稳定性。

## 实现内容

- `server.py` 新增 `--host`、端口范围校验和 `CareerLabHTTPServer`。默认继续只监听本机，局域网访问必须显式开启。
- 新增 `GET /api/health`，通过实际执行数据库查询确认 SQLite 可用，同时返回 DeepSeek 是否已配置。
- 后台连接线程改为守护线程，主进程退出时不再等待长期空闲连接。
- SQLite 每个连接设置 10 秒锁等待和 WAL 下的 `NORMAL` 同步级别，减少短时并发写入失败。
- 训练统计跳过缺少分数或无法解析维度的旧报告，避免单条历史数据使整个统计接口返回 500。
- DeepSeek 请求超时支持 `DEEPSEEK_TIMEOUT_SECONDS`，限制在 1–120 秒，默认仍为 20 秒。
- PDF 正文长度检查由逐页重复求和改为累计计数，降低页数增长时的重复计算。
- 补充 `Referrer-Policy` 和 `Permissions-Policy` 响应头，并为核心改动增加回归测试。

## 安全边界

`--host 0.0.0.0` 只改变监听范围，不提供登录、用户隔离或公网安全配置。当前版本仍只适合本机或可信局域网演示，不应直接暴露到公网。

## 验证记录

在 Windows、Python 3.14.10、pypdf 7.1.0 环境中执行：

```powershell
python -m unittest discover -s tests -v
python -m compileall -q server.py engine.py progress.py storage.py deepseek.py resume_files.py tests
node --check public/app.js
node --check public/features.js
ruff check . --exclude .venv --exclude data
```

25 项自动化测试全部通过，静态检查通过。服务以 `--host 0.0.0.0` 启动后，首页返回 200，`/api/health` 返回 `status: ok`，安全响应头存在。
